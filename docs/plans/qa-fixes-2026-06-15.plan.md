## S-FLOW design (ready to implement)
Problem (live-confirmed): in `src/core/pdfTurboApp.ts` `signPdf` (552-623), generate-mode generates the RSA cert + downloads `.p12`/`.pem` BEFORE any sign validation. On a placement/already-signed failure the user gets orphan cert downloads + no signed PDF; the `finally` (616-622) wipes `#signGenPassword` on EVERY exit → a naive retry silently bails at the `if(!genPw)` guard (565) while the stale error stays on screen. Default placement x=360/w=200 is off-page for pages <560pt wide (e.g. 500×400 fixture).
Signer validation order today (`src/signing/pdfSigner.ts` sign() 53-73): validateSignOptionsShape → `_assertNotAlreadySigned` → loadP12 → validatePageIndex → validateRect. All cert-independent EXCEPT loadP12.
Fix steps:
1. `pdfSigner.ts`: extract module fn `export function isPdfSigned(bytes: Uint8Array): boolean` (the regex from `_assertNotAlreadySigned`); refactor `_assertNotAlreadySigned` to throw based on it. Add `export` to signing/index.ts.
2. `pdfSigner.ts`: add `async preflight(pdfBytes, page, rect): Promise<void>` = `_assertNotAlreadySigned` + load doc + `validatePageIndex` + `validateRect` (the cert-free checks). Refactor `sign()` to call `preflight` (DRY) before `loadP12`.
3. `signingHandler.ts`: `sign(form, preassembled?: Uint8Array)` — use `preassembled ?? await app.assemblePdfBytes()` to avoid double-assembly.
4. `pdfTurboApp.signPdf`: assemble ONCE up front → `new PdfSigner().preflight(bytes, page0, rect)` in try/catch → on SignError show `sign.error.<code>` + return BEFORE cert-gen → then cert-gen/upload → `_signingHandler.sign(form, bytes)`.
5. Stop wiping `#signGenPassword` in the `finally`; keep the scrub in `closeSignModal` only (so a validation-failure retry keeps the typed password). Keep `signPassword` clear behavior consistent.
6. [P3 sub-item] Default placement: clamp the default rect to the target page OR shrink defaults so they fit small pages.
TDD: unit-test `isPdfSigned` (signed vs unsigned bytes) + `preflight` (throws INVALID_RECT for off-page rect, ALREADY_SIGNED for signed bytes, passes for valid) in `tests/signing/`; re-verify live that generate-mode with an off-page rect does NOT download a cert.
